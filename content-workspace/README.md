# content-workspace — Content Creator workspace

This folder is mine alone. It holds every brief, draft, finished piece, observed response, and lesson for content work in this project.

- `briefs/` — one file per piece: what was asked, who it is for, where it goes.
- `drafts/` — raw thought and drafts toward each piece.
- `pieces/` — the finished piece as delivered.
- `responses/` — what actually happened after it went out: read, reactions, silence.
- `lessons/` — what the live truth taught: what worked, what fell flat.

A piece left only in chat will be lost; the finished version lands here.
