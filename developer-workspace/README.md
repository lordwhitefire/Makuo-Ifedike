# developer-workspace

This is the Developer's home base for the `ifedike_makuo` project. It contains briefs, notes, plans, and reports for tasks executed here. It is yours alone — other agents should not write here.

- `briefs/` — one file per task: what was asked, what done looks like
- `notes/` — verification notes — current state, change points, dependencies
- `plans/` — change plans (smallest step, invariants, order)
- `reports/` — honest report after each task (built, verified, not verified)
